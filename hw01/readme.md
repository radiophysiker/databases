# Описание задачи проекта

Целью проекта является проектирование структуры баз данных для мобильного приложения с бонусной (поощрительной) системой.

Приложение предназначено для фиксации действий пользователей, начисления бонусных баллов за выполнение этих действий, а также последующего использования накопленных баллов для получения виртуальных товаров и дополнительных функциональных возможностей.

## Архитектура хранения данных

Хранение данных реализуется с разделением по типам нагрузки и требованиям к данным.

### 1. Транзакционная подсистема (OLTP)

Транзакционная подсистема предназначена для хранения и обработки основных бизнес-данных приложения:

* учет пользователей;
* начисление и списание бонусных баллов;
* учет операций по бонусным счетам;
* хранение информации о виртуальных товарах.

Для данной подсистемы требуется обеспечение строгой согласованности данных, поддержка ограничений целостности и корректная работа конкурентных операций. В качестве системы управления базами данных используется **PostgreSQL**.

### 2. Аналитическая подсистема (OLAP)

Аналитическая подсистема предназначена для накопления и анализа событий пользовательской активности, включая:

* просмотры экранов приложения;
* переходы между разделами;
* иные пользовательские действия.

Данные аналитической подсистемы используются для анализа поведения пользователей и последующего улучшения игровых механик приложения. Для хранения и обработки данных данного типа используется **ClickHouse**, оптимизированный для аналитических запросов и работы с большими объемами событий.

## Обоснование выбора архитектуры

Разделение транзакционной и аналитической подсистем позволяет:

* обеспечить целостность и надежность бизнес-данных;
* снизить нагрузку на транзакционную базу данных;
* повысить эффективность аналитических запросов и обработки событий.

Данная архитектура соответствует требованиям систем с высокой транзакционной нагрузкой и необходимостью последующего аналитического анализа.
